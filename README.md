# NoCrashing 2: the next paper

Continues [NoCrashing](https://github.com/K144U/NoCrashing) (M.Tech thesis,
AKTU: measuring, modelling and fixing examination result portals under
scheduled surges). The first paper is in [`paper/`](paper). This repository
adds the second: waiting rooms that work under refreshing students
([`paper2/`](paper2)), a study of how students behave on a slow result page,
and the preparation for the 2027 field season.
